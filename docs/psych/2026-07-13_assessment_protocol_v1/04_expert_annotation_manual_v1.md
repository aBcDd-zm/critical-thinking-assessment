## 1. 目的

本手册用于建立独立、可追溯的专家金标准，评估模型能否从用户真实语言行为中识别六维审辩式思维表现。专家的任务不是判断用户的方案“对不对”，而是根据统一 BARS 标记证据并评价所展示的思维行为。

专家标签是模型验证的参照，不应被模型预测反向修改。正式标注时，专家不得看到机器分数、机器解释、另一位专家的标签或外部测验分数。

## 2. 标注单位

| 单位 | 定义 | 用途 |
| --- | --- | --- |
| 会话 `session` | 一名参与者的一次完整测评 | 有效性、完整性、总体数据质量 |
| 阶段 `stage` | S1–S6 中一个核心问题及其一次可选干预 | 阶段级 BARS 评分 |
| 话轮 `turn` | 一条系统、助手或用户消息 | 定位回答来源 |
| 证据跨度 `evidence_span` | 用户原话中支持判断的最小充分连续或非连续片段 | 可追溯评分和证据一致性分析 |
| 维度 `dimension` | 六个预定义构念之一 | 阶段级及会话级评分 |

六个维度键固定为：

- `problem_definition`
- `evidence_evaluation`
- `reasoning_argumentation`
- `multiple_perspectives`
- `integrative_decision`
- `dynamic_adjustment`

不得新增“表达能力”“领导力”“同理心”“专业度”等隐含评分维度。

## 3. 标注角色与资格

### 3.1 建议配置

- 至少 2 名独立标注专家；
- 1 名裁决专家，原则上不参与该案例的首次独立评分；
- 专家应接受心理测量、审辩式思维、教育评估或相关行为编码训练中的至少一种；
- 项目负责人记录专家背景、培训时长和利益冲突，但研究数据中使用匿名标注员编号。

### 3.2 标注前培训

1. 阅读四份 v1 规范和完整情境材料；
2. 共同讨论构念边界，但不记忆“标准答案”；
3. 独立标注 3–5 个示例，再讨论分歧；
4. 独立完成 10–15 个校准案例；
5. 计算一致性、整理争议点、修订说明；
6. 达到第 11 节门槛并冻结手册后，进入正式标注。

校准案例不进入最终锁定测试集，除非在冻结后由全新专家重新盲标。

## 4. 盲评与独立性

正式标注必须满足：

- 案例使用随机匿名编号，隐藏姓名、联系方式和无关身份信息；
- 专家看不到 AI 预测、AI 证据、AI 解释和置信度；
- 专家看不到其他专家的评分和备注；
- 如有 CCTST 或其他外部量表结果，须在本项目标签冻结后才可合并分析；
- 两位专家完成并提交独立结果前不得讨论具体案例；
- 标注顺序随机化，必要时平衡高低质量案例，减少顺序疲劳；
- 同一专家单次连续标注建议不超过 60–90 分钟，并记录异常中断。

## 5. 标注工作流

### 第一步：会话有效性检查

先判断会话状态：

| 状态 | 标准 |
| --- | --- |
| `valid` | 主要阶段可读、角色正确、回答由参与者产生，无严重技术污染 |
| `valid_with_missing` | 部分阶段缺失，但其余部分可独立评分 |
| `invalid` | 大面积缺失、角色错乱、文本损坏、明确代答/复制或无法确认内容来源 |

标为 `invalid` 时仍记录原因，但不输出会话级数字分数。

### 第二步：通读但暂不评分

通读完整会话，了解信息出现顺序和用户是否因新证据合理调整。不得在此步凭总体印象先填分。

### 第三步：标记证据跨度

按照阶段顺序，在用户原话中标出与目标维度有关的最小充分片段：

- 片段须足以让另一位专家理解判断依据；
- 不为追求短而截掉必要条件或否定词；
- 不整段全选以逃避定位；
- 系统问题和追问内容不选为用户证据；
- 若一句话支持多个维度，为每个维度建立独立标注并说明关系；
- 语义重复只保留一条主证据，其他标记 `duplicate_of`；
- 可将相隔的两段原话组成一个证据组，但必须分别保存跨度。

### 第四步：判断证据有效性和强度

| 等级 | 判定 |
| --- | --- |
| `invalid` | 与目标行为无关、来自系统提示、纯复制、无法理解或错误归因 |
| `weak` | 有相关提及，但零散、模糊或缺少必要联系 |
| `moderate` | 已展示维度的基本行为，能够支持 3 分附近判断 |
| `strong` | 要素清晰、相互连接、可核验，并能区分较高 BARS 等级 |

强度不是分数。专家必须回到具体维度 BARS 判断等级。

### 第五步：给阶段级 BARS 分

1. 查看该阶段主测维度及已标证据；
2. 从最接近的锚点开始，核对该等级的全部关键要求；
3. 再与相邻一级比较；
4. 填写 1–5 或 `IE`；
5. 用一句话说明“为何是该级”；
6. 用一句话说明“为何未达到更高一级”，5 分则说明完整性依据；
7. 记录专家置信度 `high`、`medium` 或 `low`。

### 第六步：形成会话级维度判断

依据 `scoring_spec_v1` 的预注册阶段权重计算，不凭总体印象重新给分。若主测阶段为 `IE`、仅有辅测证据，标记 `partial_coverage` 并交裁决。

### 第七步：提交并锁定

首次提交后，专家不能自行覆盖原结果。如发现操作错误，通过更正记录保存旧值、新值、原因和时间。

## 6. 低分与证据不足的边界

| 情况 | 结果 | 示例性质 |
| --- | --- | --- |
| 用户明确作答，但只给结论、复述或无依据接受权威 | 1 分 | 已观察到低水平行为 |
| 用户出现一个相关要素但不足以形成基本行为 | 2 分 | 有弱证据，不等于缺失 |
| 用户未作答、完全跑题、技术截断或该维度没有展示机会 | `IE` | 不能推断能力高低 |
| 用户回答很短但准确完成目标行为 | 依 BARS 可评 3–5 | 字数不是分数 |
| 用户回答很长但没有目标行为 | 1、2 或 `IE` | 取决于是否有有效作答 |

遇到“看似合理但证据不足”的回答，不得因专家同意其结论而加分。遇到“专家不同意方案但论证完整”的回答，也不得因观点偏好扣分。

## 7. 特殊案例规则

### 7.1 追问与动态信息

- 追问后的用户新增内容可以计分，并标记 `elicitation_source = followup`；
- 系统问题中已经列出的要素，用户仅机械照抄时不构成高等级证据；
- 用户将新信息纳入判断并解释调整，可支持 `dynamic_adjustment`；
- 用户有理由地保持原判断也可能是高水平动态调整，关键在于评估新信息而非必须改变结论。

### 7.2 矛盾与自我修正

- 先后观点不同不自动扣分；
- 若用户识别变化原因、修正假设或限定结论，可视为更新证据；
- 若矛盾未被解释且直接影响等级，标记 `unresolved_contradiction` 并交裁决；
- 不得只选对评分更高的句子而忽略反向证据。

### 7.3 外部知识与事实错误

本测评不是产品管理知识考试。仅当事实错误破坏了证据评价或推理链时才影响相应维度；陌生术语、行业经验不足或非标准表达本身不扣分。

### 7.4 语言与表达差异

允许口语、简写、错别字和不完整句。只要含义可确认，就按思维行为评分。无法确认含义时标记不确定，不自行补全用户意图。

## 9. 独立双标与裁决

### 9.1 双标范围

- 校准阶段：全部案例由至少 2 名专家独立标注；
- 正式金标准测试集：全部案例独立双标；
- 训练集若受资源限制，可在一致性达标后采用部分双标，但建议至少 20% 随机双标，并覆盖各分数段和 `IE`；
- 任何模型低置信度、异常案例或申诉案例均需双标或裁决。

### 9.2 自动进入裁决的条件

- 同一阶段同一维度相差 2 分及以上；
- 一人评数字分、一人评 `IE`；
- 对关键证据有效性判断不一致；
- 一人标记会话无效而另一人标记有效；
- 差 1 分但位于项目关注的决策边界，或任一专家置信度为 `low`；
- 存在未解决矛盾、明显提示复述或疑似代答。

### 9.3 裁决流程

1. 系统向裁决专家展示原始材料和两份独立标签，不展示机器结果；
2. 裁决专家先独立定位证据和初判，再查看分歧理由；
3. 依据冻结 BARS 决定最终标签，不简单取平均或少数服从多数；
4. 填写 `adjudication_reason`，指出采用或否定某证据的原因；
5. 保存两份原始标签、裁决标签和全部版本；
6. 若分歧暴露手册缺陷，先记录问题；正式批次中不得无版本升级地悄然改规则。

## 10. 金标准样本与数据划分

### 10.1 样本量路线

- **校准样本**：10–15 例，用于培训和发现手册问题；
- **小规模预测试**：60–100 例，可用于检查流程、初步一致性和模型误差，但不足以宣称普适效度；
- **监督模型开发**：如要训练稳定模型，建议继续积累到至少 200–300 例，并根据分数分布和模型复杂度重新做功效/学习曲线判断；
- **锁定测试集**：从正式双标样本中预先保留 60–100 例，模型和提示冻结前不可查看。

上述为项目规划起点，不是保证有效性的固定门槛。最终样本量须结合分布、缺失、效应量和研究设计计算。

### 10.2 划分原则

- 按参与者划分训练、验证和测试集；
- 同一参与者、同一回答的改写或重复评分不得跨集合；
- 分层时关注维度等级、`IE` 和会话质量，但不得使用测试结果反向挑样本；
- AI 伪标签、规则生成标签和未裁决分歧不得进入金标准测试集；
- 划分清单、随机种子和生成代码提交号必须保存。

## 11. 一致性与质量门槛

### 11.1 校准期操作门槛

| 指标 | 目标 | 处理 |
| --- | ---: | --- |
| 加权 kappa（1–5 序数分） | `≥ 0.70` | 可进入下一阶段 |
| ICC（连续维度分） | `≥ 0.70` | 可进入下一阶段 |
| 证据跨度/证据单元 F1 | `≥ 0.70` | 可进入下一阶段 |
| `IE` 与数字分一致率 | `≥ 0.85` | 可进入下一阶段 |

若主要指标为 `0.60–0.69`，须分析分歧、修订手册并追加校准；若 `< 0.60`，暂停正式标注并重新训练。门槛是本项目的操作性质量闸门，不等于对测量效度的充分证明。

### 11.2 持续质量检查

- 每批完成后计算总体和分维度一致性；
- 随机插入少量已裁决锚点案例，监测标注漂移；
- 记录标注时长、低置信度率和裁决率；
- 若某维度连续两批一致性下降，暂停该维度并复训；
- 不删除难例以美化指标，须报告排除规则和数量。

## 12. 与外部效标的关系

如使用 CCTST 或其他受版权/许可约束的量表：

- 先确认正式授权、施测条件和计分权限；
- 外部量表由独立流程施测并使用匿名 ID 关联；
- 专家标注冻结前不得看到外部得分；
- 外部得分用于收敛/关联效度研究，不作为修改单个专家标签的答案；
- 预注册主要假设、排除标准和统计方法，报告相关及其置信区间，不将相关解释为因果。

## 13. 隐私、伦理与安全

- 参与者在采集前完成知情同意，知道对话会被算法和专家分析；
- 研究数据使用匿名 ID，身份映射表与对话分开保存并限制权限；
- 标注界面只展示完成任务所需的信息；
- 专家不得下载、传播或将原始对话输入未经批准的第三方工具；
- 报告和论文引用须去标识化，必要时做不改变含义的最小改写并说明；
- 建立撤回、删除、访问记录和数据保留期限；
- 出现个人敏感信息时标记并按研究伦理方案处理，不纳入能力评分。

## 15. v1 验收与冻结

正式标注启动前，项目负责人应确认：

- 四份规范中的六维键、阶段名、`IE`、证据强度和版本字段一致；
- 标注界面支持原文跨度、重复、风险标记、相邻等级理由和更正记录；
- 至少两名专家完成培训和 10–15 例独立校准；
- 一致性达到第 11 节门槛，或已记录暂停与修订决定；
- 裁决者、数据划分、权限、备份和撤回流程明确；
- 手册版本已冻结，正式批次开始后所有实质变化均通过新版本管理。
