# CCTST 题目设计优势与动态测评迁移建议

> 文档版本：v1
>
> 编写日期：2026-07-17
> 文档用途：总结 CCTST 的题目设置逻辑及其测量优势，为审辩式思维动态测评系统的情境、主问题、追问和评分规则设计提供参考。

## 1. 参考材料与说明

本文主要参考《基于“5E”的高中生物教学模式促进学生批判性思维形成的实践研究》所附中文版《加利福尼亚批判性思维技能测试》（CCTST）。该附件包含 34 道单项选择题，论文将其测量内容概括为推理、分析和评估三个核心技能。

论文作者组织专家组对题目进行了二次归类，将 5 个项目归为推理技能、15 个项目归为分析技能、14 个项目归为评估技能。需要注意，这一数量分配属于该论文专家组的分析结果，不应直接视为 CCTST 官方公布的逐题维度蓝图。

本文提炼的是 CCTST 可观察到的题目设计逻辑，不复制其具体题目，也不建议直接照搬原题、翻译文本或计分标准。

## 2. 核心结论

CCTST 最值得借鉴的不是“单项选择题”形式，而是它将复杂的批判性思维拆成了多个边界明确、知识门槛较低、能够客观判定的微型推理任务。

其基本设计思想可以概括为：

> 不要求被试提出多么专业或完整的解决方案，而是要求被试在给定信息下完成一个明确、可观察、可评价的思维动作。

## 3. CCTST 测量的核心技能

| 技能 | 核心含义 | 常见作答动作 |
| --- | --- | --- |
| 推理 | 根据事实、证据和条件形成假设或推出结论 | 判断什么可以推出、还缺什么信息、结论应达到何种确定程度 |
| 分析 | 识别信息之间以及论点、论据、前提和结论之间的关系 | 辨认条件关系、隐含前提、论证结构、数据关系和概念边界 |
| 评估 | 判断陈述的可信度、论证的逻辑强度及结论的正当性 | 判断证据是否充分、理由是否相关、研究设计是否支持结论、推理是否存在漏洞 |

这三类技能不是彼此孤立的。实际作答时，一道题可能同时涉及多个技能，但题目通常会突出其中一个主要认知动作。

## 4. CCTST 题目设计的主要优势

### 4.1 情境短小，降低专业背景依赖

CCTST 使用比赛、遗传概率、酒店火警、研究数据、扑克牌、交通方式和职场冲突等多种微型情境。情境的主要作用是承载推理关系，而不是考查被试是否熟悉某一行业。

其优势包括：

- 所需事实尽量在题目中直接给出；
- 被试不需要掌握完整的专业工作流程；
- 情境可以替换，但推理结构保持稳定；
- 降低教育背景、职业经验和行业知识对测量结果的干扰；
- 更容易将错误归因于推理过程，而不是情境陌生。

### 4.2 每题只要求完成一个清楚的思维动作

CCTST 很少使用“你怎么看”这类没有边界的问题，而是要求被试完成相对明确的任务，例如：

- 判断哪项结论一定成立；
- 判断哪项结论可能成立但不能确定；
- 找出论证中缺失的前提；
- 判断哪一种解释最合理；
- 判断论据是否真正支持结论；
- 找出满足全部条件的方案；
- 判断还需要什么信息才能证明某项主张。

这种方式为被试提供了明确的作答目标，也为评分者提供了稳定的评分对象。

### 4.3 信息边界清楚，答案主要来自题内证据

CCTST 通常会在题目中给出作答所需的事实、数据、条件或规则。被试需要判断的是这些信息之间的逻辑关系，而不是调用大量外部知识。

这一设计具有较强的测量价值：

- 明确区分“没有使用好信息”和“根本不知道背景知识”；
- 避免由行业经验决定答案质量；
- 便于复核题目是否存在信息缺失；
- 便于建立标准答案、关键证据和错误类型之间的对应关系；
- 使不同被试面对的证据基础更加一致。

### 4.4 难度主要来自推理步骤，而不是语言和术语

优质的 CCTST 式题目不是通过增加专业术语或拉长材料制造难度，而是通过以下方式提高认知要求：

- 增加需要同时满足的条件；
- 要求区分充分条件与必要条件；
- 要求判断结论的确定程度；
- 要求识别证据与结论之间的缺口；
- 要求比较多个解释；
- 要求从图表、规则或研究结果中提取关系；
- 要求发现相关关系不能自动证明因果关系。

因此，测验难度与目标思维技能之间具有更直接的联系。

### 4.5 错误选项具有诊断意义

CCTST 的干扰项通常不是随机编造的错误答案，而是对应常见推理偏误，例如：

- 将“可能”扩大为“肯定”；
- 在证据不足时作出确定判断；
- 混淆充分条件和必要条件；
- 将相关关系解释为因果关系；
- 忽略样本范围或样本偏差；
- 忽略其他可能解释；
- 使用与结论无关的理由；
- 用态度、立场或价值偏好代替证据；
- 将多种可能方案压缩成非此即彼；
- 只看到支持性证据，忽略反例和限制条件。

这使题目不仅能够判断“是否答对”，还能够帮助识别“可能错在什么地方”。在动态测评中，这些错误类型可以直接转换为追问触发条件。

### 4.6 重视结论强度与证据强度的匹配

CCTST 中大量题目并不只区分“正确”和“错误”，还要求区分：

- 必然成立；
- 很可能成立，但也可能不成立；
- 很可能不成立，但仍有可能成立；
- 根据现有信息无法确定。

这类题目测量的是认识上的谨慎程度，即被试能否避免让结论超过证据所能支持的范围。这对于审辩式思维测评非常重要，因为高质量推理不等于总能给出确定答案，也包括在证据不足时合理保留判断。

### 4.7 共享材料可以连续测量不同技能

CCTST 会让若干题目共享同一份流程图、数据图、规则集合或职场情境，然后分别提出不同问题。例如，一道题检查条件应用，下一道题检查数据解释，再下一道题检查结论是否与数据一致。

其优势包括：

- 减少重复阅读和情境切换；
- 控制不同题目所依赖的背景信息；
- 在同一情境中观察多种思维动作；
- 可以比较被试在事实识别、关系分析和论证评估上的表现差异；
- 适合扩展为“初次判断—追问—新信息—修正判断”的动态流程。

### 4.8 情境多样，降低单一领域经验的系统性影响

CCTST 不围绕一个专业场景连续设置全部题目，而是使用多个领域的微型材料。即使某位被试对其中一个情境不熟悉，也不至于系统性影响整个测验。

这种多情境结构有助于判断某种思维能力能否跨情境迁移，也减少“熟悉一个行业就能在全部题目中占优势”的风险。

### 4.9 评分对象稳定，便于量化和复核

CCTST 采用单项选择和 0/1 计分，评分规则清晰，结果易于统计。虽然这种形式无法完整观察被试的思考过程，但它具有以下工程优势：

- 不同评分者得到的结果一致；
- 容易进行题目难度、区分度和信效度分析；
- 可以建立明确的题目—维度映射；
- 可以保存每题答案并进行人工复核；
- 适合用于前测、后测和群体比较。

动态测评不必复制 0/1 计分，但应继承其“评分对象明确、证据可追溯、规则可复核”的特点。

## 5. CCTST 中常见的问题结构

以下分类用于理解设题方式，不代表官方逐题分类。

| 问题结构 | 典型提问 | 主要观察点 |
| --- | --- | --- |
| 结论强度判断 | 根据现有信息，结论是必然、可能还是无法确定？ | 是否让结论强度与证据匹配 |
| 条件关系转换 | 某条件成立时，哪些结果可以或不可以推出？ | 是否理解充分条件、必要条件和逻辑等价 |
| 约束组合 | 哪个方案同时满足所有规则？ | 是否能整合多项条件并排除冲突项 |
| 论证结构识别 | 这段话省略了哪个前提或结论？ | 是否能区分论点、论据、假设和结论 |
| 研究证据分析 | 数据是否支持研究者的结论？ | 是否关注样本、对照、变量和替代解释 |
| 因果推断评估 | 两个现象同时变化，是否足以证明因果？ | 是否混淆相关与因果 |
| 论据质量评价 | 这段推理好不好，原因是什么？ | 理由是否相关、充分和可信 |
| 图表与流程应用 | 根据图表或规则，某情况下应采取什么行动？ | 是否正确读取并应用结构化信息 |
| 新信息修正 | 新证据出现后，原结论的哪一部分需要改变？ | 是否能够更新判断并解释变化依据 |

## 6. 对动态情境测评的迁移价值

本项目不适合直接改成传统 CCTST 选择题，但可以采用“CCTST 的测量逻辑 + 动态访谈的过程证据”。

推荐的基本流程为：

```text
给出边界清楚的基础材料
→ 要求完成一个明确的判断动作
→ 记录初始结论及其依据
→ 根据缺失证据或推理偏误进行定向追问
→ 释放一条具有诊断价值的新信息
→ 要求保留、修改或推翻原判断
→ 记录修改内容和理由
```

这一结构兼顾了两类优势：

- CCTST 的任务清晰、信息受控、评分稳定；
- 动态访谈的过程可见、追问可调、修正能力可观察。

## 7. 推荐的半开放式作答合同

为了减少“问题讲不清楚”和“被试不知道怎么发挥”，每个阶段应明确要求被试输出什么。可以采用以下结构：

### 7.1 问题界定

> 请指出当前必须作出的一个核心判断，并列出影响这个判断的两项已知条件。

### 7.2 证据分析

> 根据现有材料，目前最多能得出什么结论？还有什么不能确定？

### 7.3 信息需求

> 如果只能补充一类信息，哪类信息最可能改变你的判断？为什么？

### 7.4 论证评估

> 某位参与者提出了一个判断。这个判断的理由是否充分？缺少什么或忽略了什么？

### 7.5 动态调整

> 新信息出现后，你原判断中的哪些内容应当保留、修改或推翻？请指出对应证据。

### 7.6 综合结论

> 请按“结论—主要依据—仍不确定的信息—什么情况会改变结论”四部分给出最终判断。

这种半开放格式不会限制被试只能选择固定答案，但能让回答具有统一、可比较的结构。

## 8. 对现有“产品上线前 48 小时”情境的启示

现有六阶段动态结构具有连续性和过程观察优势，但部分主问题的回答空间过大，容易混入产品管理经验、行业术语、长文本表达和猜测评分意图等非目标因素。

| 现有提问方向 | 潜在问题 | CCTST 式改造方向 |
| --- | --- | --- |
| 先把哪件事定下来 | “哪件事”的范围不明确 | 要求指出一个核心判断和两项约束 |
| 第一步会查什么 | 可能依赖软件研发经验 | 给出若干已知证据，要求指出最关键的证据缺口及理由 |
| 先处理谁的担忧 | 容易成为立场或偏好题 | 要求比较各方主张所依据的证据、影响范围和未说明假设 |
| 你会怎么安排上线 | 方案空间过大，难以稳定评分 | 先判断证据支持何种程度的结论，再要求提出有限方案 |
| 你会改变安排吗 | “改不改”本身诊断价值有限 | 要求指出哪条新证据改变了哪项判断，以及改变幅度 |
| 最终如何安排上线 | 容易与初步决策重复 | 按统一结构输出结论、依据、不确定性和调整条件 |

## 9. 题目设计检查清单

设计或评审每一个情境问题时，建议检查：

- [ ] 本题主要测量的思维动作能否用一个动词说清楚？
- [ ] 被试是否知道需要回答哪些具体内容？
- [ ] 作答所需的主要事实是否已经在材料中给出？
- [ ] 不熟悉该行业的人是否仍能依靠题内信息作答？
- [ ] 高质量回答与低质量回答之间是否有明确差异？
- [ ] 是否区分了事实、假设、判断、理由和结论？
- [ ] 是否允许被试在证据不足时表达合理的不确定性？
- [ ] 追问是否对应一种具体的证据缺失或推理偏误？
- [ ] 新释放的信息是否真的可能改变原判断？
- [ ] 是否能够记录判断修正前后的变化及理由？
- [ ] 评分依据是否来自可引用的回答证据，而不是语言风格或篇幅？
- [ ] 同一题是否过度依赖专业知识、管理经验或特定文化背景？

## 10. 使用边界

CCTST 的结构也存在局限：

- 选择题难以完整呈现真实思维过程；
- 部分翻译题语言生硬，增加了理解负担；
- 某些情境带有特定文化和时代背景；
- 固定答案不适合直接评价复杂现实决策；
- 0/1 计分无法反映部分正确、合理保留和修正过程。

参考论文也指出，中译版存在题目偏难、翻译主要追求语义等值、对学生理解水平和文化背景考虑不足等问题。因此，本项目应借鉴 CCTST 的任务分解、证据约束、错误诊断和可复核设计，而不应直接复制原题语言、固定选项或单一计分方式。

## 11. 最终建议

本项目可以保留“六阶段情境—定向追问—动态信息—最终报告”的总体结构，但应按照以下原则重构问题：

1. 每个阶段只突出一个主要认知动作；
2. 让情境承担信息载体作用，而不是专业知识筛选作用；
3. 把主问题从宽泛的方案表达改为有输出约束的半开放任务；
4. 将常见推理偏误转化为结构化追问触发条件；
5. 记录初始判断、依据、新信息、修正内容和修正理由；
6. 评分重点放在证据使用、关系识别、结论强度和调整过程，而不是最终选择是否符合某个预设方案。

最终目标不是让被试“发挥得像一名专业项目经理”，而是让不同背景的被试都能在公平、清楚的信息条件下展示其真实的审辩式思维过程。
